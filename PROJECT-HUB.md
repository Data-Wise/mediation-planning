# 📊 Mediationverse Ecosystem — Planning Hub

> **The front door** for ecosystem-wide planning. This hub holds the *prose*
> (roadmap, decisions, standards, specs). Anything *computable* — live status,
> dependency order, CRAN sequence, "what next" — is **generated by rforge**, not
> tabulated here. See [docs/RFORGE-COMMANDS.md](docs/RFORGE-COMMANDS.md).

**Last Updated:** 2026-06-10 (planning consolidation — single hub)

## 🚀 Live status (don't hand-maintain — generate it)

```bash
cd ~/projects/r-packages
/rforge:status      # per-package health from each .STATUS
/rforge:deps        # dependency graph + topological order
/rforge:release     # CRAN submission sequence + readiness
/rforge:next        # ecosystem-aware "what should I do next"
/rforge:thorough    # full rollup (status + deps + health + CRAN)
```

CI/CD pass-fail **badges** live in `mediationverse/STATUS.md` (the one thing rforge
can't render).
