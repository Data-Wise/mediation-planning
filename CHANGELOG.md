# Changelog

All notable changes to mediation-planning are documented here.

## 2026-06-10 (Planning Consolidation — single hub)

Consolidated ecosystem-wide planning that was scattered across three loci
(this repo, `medfit/planning/`, `mediationverse/STATUS.md`) plus rforge.

### Added
- `ECOSYSTEM-MANIFEST.yaml` — authoritative registry of the 7 packages (paths,
  roles, repos, CRAN state).
- `docs/RFORGE-COMMANDS.md` — the dynamic layer: which rforge command replaces
  which hand-maintained table (status/deps/CRAN-order/next).
- `docs/design/` — API & naming design rationale (4 docs) relocated from
  `medfit/planning/`: `API-DESIGN-DECISIONS`, `GENERIC-FUNCTIONS-RESEARCH`,
  `GENERIC-NAMING-STRATEGY`, `FUNCTION-NAMING-DEEP-DIVE` (+ provenance README).
- `proposals/MEDIATIONVERSE-PROPOSAL.md` — relocated from `medfit/planning/`.
- `archive/README.md` — index of superseded docs.
- Root `~/projects/r-packages/.rforge.yaml` — local rforge `kind` hint (untracked).

### Changed
- **`PROJECT-HUB.md`** rewritten as a lean *front door* — removed hand-maintained
  status tables / "this week" task lists / decision blocks (now `/rforge:status`,
  `:next`); links manifest, rforge commands, and the doc map.
- **`docs/ECOSYSTEM-COORDINATION.md`** — merged additive content from medfit's
  `ECOSYSTEM.md` (API compatibility, migration guides, coordination points);
  replaced the drift-prone "current versions" snapshot with an `/rforge:status` pointer.
- **`README.md`** — points to manifest + rforge for live status; refreshed doc map;
  added missingmed; removed stale per-package status table.

### Hybrid model
Prose (roadmap, decisions, standards, specs) stays in markdown here; computable
facts (status, dependency order, CRAN sequence, "what next") are generated by rforge.
Per-package status lives in each package's `.STATUS` file.

### Archived (superseded)
- `COORDINATION-HUB-BRAINSTORM.md` (realized by rforge), `ECOSYSTEM-REVIEW-SUMMARY.md`,
  `SESSION-SUMMARY.md`, `MEDSIM-IMPLEMENTATION-STATUS.md` → `archive/`.

### Follow-up (other repos, separate PRs)
- medfit: replace the relocated ecosystem docs with pointer stubs (Phase 2).
- mediationverse: thin `STATUS.md` to badge wall + rforge/hub pointers (Phase 3).
